# Mission 01 - Computer basics

## 1. Task / objective

The objective of Mission 01 was to understand the core fundamentals of how computers work. This included tracing an everyday computer activity through the IPOS cycle (Input, Processing, Output, Storage), classifying common hardware and software items, and identifying embedded computer systems around us in everyday life.

## 2. Work completed

I completed all three tasks for this mission:
- Traced the activity of typing and saving a study document through the IPOS stages.
- Listed and classified four hardware items and four software examples (operating system, application, and utility software).
- Identified three everyday computer systems outside of normal laptops and smartphones.

Here is the detailed work for each task:

### Task 1.1 - Trace one activity using IPOS

Activity chosen: Typing a college assignment document in a text editor and saving it to the drive.

Stage 1: Input
- What happens: I press letters and space on the keyboard to write words, and use the trackpad to position the cursor.
- Hardware involved: Keyboard and trackpad.

Stage 2: Processing
- What happens: The CPU receives the keystroke signals from the keyboard, interprets the key codes, stores the characters temporarily in RAM, and calculates how the text layout should be drawn.
- Hardware involved: CPU (processor) and RAM (system memory).

Stage 3: Output
- What happens: The graphics processor and screen display the newly typed words inside the text editor window so I can see what I just typed.
- Hardware involved: Display screen / monitor.

Stage 4: Storage
- What happens: When I press save, the CPU instructs the storage controller to write the document data from RAM into a permanent file on the drive so it stays saved even after power is turned off.
- Hardware involved: Solid State Drive (SSD).

Movement through IPOS:
The activity starts with input when my fingers touch the physical keys. That input data is sent to the processor, which processes the keystrokes and holds them in memory. Next, the computer produces output by showing the words on the screen so I can verify them. Finally, when I save the file, the data moves to long term storage so it can be opened tomorrow.

### Task 1.3 - Computer systems around you

System 1: ATM (Automated Teller Machine)
- Main purpose: Allows people to safely withdraw cash, check bank account balances, or deposit money without waiting in line inside a bank.
- One input: Numeric pin pad or touch screen where the customer enters their PIN and transaction choice.
- One output: Cash dispenser slot that delivers paper currency, or receipt printer.

System 2: Smart Traffic Light
- Main purpose: Regulates the flow of cars and pedestrians at a street crossing to avoid collisions and keep traffic moving smoothly.
- One input: Push button pressed by a pedestrian wanting to cross, or an underground sensor detecting a car.
- One output: Colored signal lamps (green, yellow, and red) telling drivers and pedestrians when to go or stop.

System 3: Metro Ticket Vending Machine
- Main purpose: Allows commuters to buy travel tokens or recharge transit cards quickly at a train station.
- One input: Touch screen where the user selects their destination station.
- One output: Ticket dispenser slot that prints the travel ticket with a QR code.

## 4. My understanding

Before this mission, I used to think of a computer as just a screen and keyboard. Now I understand the IPOS cycle: computers take inputs from humans or sensors, process the data using the CPU and RAM, present outputs so we know what happened, and store things permanently on an SSD or hard drive.

I also learned the clear separation between hardware (physical parts you can touch) and software (instructions that run on hardware). Within software, understanding the difference between the operating system, applications, and utility tools helped me see why each has a different role.

## 5. Difficulties faced

At first, I was confused about whether RAM counts as storage in the IPOS model. It holds data, so I thought it might be storage.

## 6. How I resolved them

I realized that RAM is temporary working memory that clears when the computer turns off, while storage means non-volatile storage like an SSD or hard drive where files are kept permanently. So RAM belongs to the processing stage, while the SSD is the storage stage.
