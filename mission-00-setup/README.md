The goal of this mission was to prepare my computer workspace for the assignment. - python3 --version: used to check the installed Python version. Output showed Python 3.9.6.

- mkdir: used to create all the mission folders and directories.
- git init -b main: used to initialize git tracking on the main branch.

## 4. My understanding

A repository is like a digital project binder that records every change made to files over time. Git acts like an automatic diary so if I make an error or break something later, I can easily see what was changed and restore an earlier working version.

Separating the assignment into dedicated mission folders keeps everything tidy and clean. Instead of cluttering all notes, scripts, and practice files in one big folder, each topic has its own place. It also makes it much easier for an instructor to review my work mission by mission.

## 5. Difficulties faced

At the start, I had to be very careful to name the repository correctly using the exact last four digits of my USN (8084) and keep everything lowercase with hyphens. I also had to make sure I was in the right directory before creating the folders.

## 6. How I resolved them

I ran the pwd command in terminal to confirm my exact path before creating anything. I double checked the assignment guide to ensure the folder name was typed exactly as digital-detective-8084 without any uppercase letters or spaces.
